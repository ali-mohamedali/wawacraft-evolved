*include/common.hpp* is a header file holding common data or functions 
available to the entire program.  It includes currently the variables 
PROGRAM​_NAME, PROGRAM​_NAME​_FORMAL, PROGRAM​_VERSION, among others, 
that inform the program about itself.

include/common.hpp delivers all of its functions in the namespace common.
