The *settings* namespace is a namespace provided by the header file
include/program/settings.hpp.  It is part of [[./module:program.org][module:program]].

All that is provided by namespace:settings are the classes and
functionality pertaining to registering of settings objects and their
management (see [[./abstract/commandline-parsing.org][Command line parsing]]).
