The class windows::window is a class that registers a window in the system's window manager.

1. Description

Initialize this whenever you would like to use a window, and interface with it to configure your window.

Good practice is to be frugal about calls inquiring the window's attributes. Store results of calls once and throw them out, as you never know what the expense is for the library or the system.

2. Specification

2.1. windows::window::window(windows::window::resolution gwidth, windows::window::resolution gheight, std::string gname)

The constructor for a window.

gwidth is given width of the window. gheight is the given height of the window. gname is the given name of the window.

2.2. windows::window::~window()

The destructor for a window. Destroys the window in the system window manager and destroys the window's resources.

2.3. void windows::window::setname(std::string gname)

A mutator on the window name(title).

gname supplies the window title.

2.4. bool windows::window::valid()

A function returning a value indicating whether or not the window is still registered and valid.

Returns windows::window::YES if yes and windows::window::NO if not.

2.5. bool windows::window::shouldclose()

A function returning a value indicating whether or not the window should close. This is for use of handling an event/render loop.

Returns either windows::window::YES or windows::window::NO.

2.6. windows::window::resolution windows::window::getwidth()

A function returning the width of the framebuffer of the window in pixels.

2.7. windows::window::resolution windows::window::getheight()

A function returning the height of the framebuffer of the window in pixels.

2.8. std::string windows::window::getname()

A function returning the title of the window as a string.

2.9. static const bool windows::window::YES

A value indicating affirmation or success.

2.10. static const bool windows::window::NO

A value indicating 'no' or failure.

2.11. Misc.

windows::window::resolution is a typedef for int.
