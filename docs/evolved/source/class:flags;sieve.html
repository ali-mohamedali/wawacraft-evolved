The class class:flags::sieve, found in header file include/program/flags.hpp, and part of namespace:flags, is a class intended to assist the parser in creating a homogenous sequence.

This class takes in the original invocation of the program, and filters it to a commmon medium. Included filtering processes are the example of flags all being '-​-long-like-this' and also filtering for pseudo-flags from the pseudo-flag table (see Command line parsing).

2.5. flags::sequence flags::sieve::filter()

This function filters the sequence, and then returns a corrected flags::sequence. This can be directly fed into the parser to parse.
