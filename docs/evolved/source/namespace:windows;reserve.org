The namespace *windows:reserve* - part of [[./namespace:windows.org][namespace:windows]] - is a
reserved namespace for utility functions for the namespace.  It is used for
initializations of libraries amongst other things that don't deal with
the concerns of the user.

* Description

This namespace is not documented because it would expose inner
workings of the class and underlying API level, which documentation I
forbid to do.
