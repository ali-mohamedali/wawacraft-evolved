The class *reserve* - part of [[./namespace:windows.org][namespace:windows]] - is a class holding
reserved static functions for the namespace.  It is used for
initializations of libraries amongst other things that don't deal with
the concerns of the user.

* Description

Don't initialize an object of this thing, it's useless anyway!

The only thing that should be used is its public functions in
discipline, not out of desire.  Anything else is truly unfounded.

* Specification

** static void windows::reserve::end()

Terminate all library resources.  Use this when you are done using
utilities from [[./namespace:windows.org][namespace:windows]], usually at the end of the program
and in your driver function.
