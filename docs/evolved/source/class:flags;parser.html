The parser class flags::parser, found in namespace:flags is the final class in the command line parsing pipeline, which parses and applies the invocations of the flags supplied in the invocation of the program.

1. Description

See Command line parsing.

2. Specification

2.1. flags::parser::parser(flags::flag​_table g​_flags)

This is the constructor. You can supply flags::parser::flags to be g​_flags, or set it yourself.

2.2. bool flags::parser::parse(flags::sequence g​​_sequence)

This function parses a flags::sequence, expected to be generated in format of long flags and data and marked accordingly. Since that isn't caller's concern, you should refer to class:flags::sieve for how to generate a conforming sequence for this function.

This function will report errors if flags were not given the data they expect. It will also report errors if given flags that do not have records in its flag table.

It will return flags::parser::SUCCESS if it succeeded or flags::parser::FAILURE if it failed.

2.3. static const bool flags::parser::SUCCESS

A boolean return value for success.

2.4. static const bool flags::parser::FAILURE

A boolean return value for failure;

2.5. flag​_table flags::parser::flags

The flag table the parser will compare with. Made public because writing interfacing functions will only be an incomplete interface with the flag, and it isn't main concern.
