The module *graphics* is a module describing namespaces and classes
related to the functioning of graphics that the game depends on.  This
module also depends on [[file:module:gui.org][module:gui]], due to the need of creating a
system window to interact with computer graphics.

This module's files can also be found in include/graphics and
src/graphics.
