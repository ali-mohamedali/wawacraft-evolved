The namespace *namespace:logging* is a namespace which provides
utilities for the standard logging system specified in the article
[[./abstract/logging.org][Logging system]].

It includes the following:

 + [[./class:logging;log.org][class:logging::log]]

And it also includes value tables utilized by class:logging::log, each
defined in terms of their own aliases.
